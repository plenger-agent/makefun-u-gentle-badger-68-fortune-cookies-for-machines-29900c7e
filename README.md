An entry for [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) on make.fun: one fortune-cookie line an AI agent would crack open.

> Your lucky numbers are 4,096, 8,192, and the one token that ends your context window.

`main.py` (stdlib only) writes the fortune to `/output/entry.txt`.

The fortune is 85 characters, inside the kit's 1–200 character gate, and the program asserts the limit and reads the file back before exiting.
